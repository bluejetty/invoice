You're in the right place. Keep the Resend tab open next to this one so you can copy values across.

  1. Open the DNS editor. Under DNS & Nameservers, click the small pencil icon next to DNS Records (where it says "18 records set").
  2. Check the existing records. The page lists your 18 current records, with a form at the top for adding new ones. Don't change or delete any of the existing records. If you see one with host _dmarc, skip the DMARC record in step 3.
  3. Add each record with the form at the top. For each one, pick the Type, type the Host, paste in the Answer, leave TTL blank, and click Add.
    • TXT, host resend._domainkey, answer: the long DKIM value from Resend
    • CNAME, host rsend, answer: its value from Resend
    • CNAME, host send, answer: its value from Resend
    • TXT, host _dmarc, answer: v=DMARC1; p=none;
    • In Resend, click the value itself or its copy icon to get the full text, since the screen shortens it.
    • Type only the host part. Porkbun adds .bluejetty.ca for you.
  4. Verify in Resend. Go back to the Resend tab, open bluejetty.ca, and click Verify or I've already added the records.
